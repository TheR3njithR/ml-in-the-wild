# Episode 4: Detect Data Drift Before Your ML Model Breaks

ML in the Wild, Episode 4. QuickBasket is a **fictional** grocery-delivery company. Every number in the video comes from this folder. The data is **synthetic**, generated by `make_data.py` (seed 41).

## What this episode teaches

A demand model can still look fine on last week's error pack while the input world has already moved. We detect that shift from the **features**, with no labels required, using the population stability index (PSI), a K S test, and a domain classifier, then hold the auto-purchase order before the stale forecast fills the warehouse.

Journey: Data → Model → Decision → Action → Feedback.

## Run it

```bash
python -m pip install -r requirements.txt
./run_all.sh
```

`run_all.sh` rebuilds the synthetic history, trains the demand model, runs the delayed-MAPE baseline, the drift monitor, the 20 April 2026 morning report, the policy comparison, and the charts. It should finish in well under a minute.

## What you get

- `make_data.py` — generator. Writes `data/daily_demand.csv` and friends.
- `drift_tools.py` — PSI, K S, domain-classifier AUC, and the small-sample PSI null.
- `model_common.py` — shared load / train / predict.
- `02_model.py` — HistGradientBoosting demand model, training window only.
- `01_baseline.py` — delayed 14-day MAPE alert (labels arrive with a 7-day lag).
- `03_detect.py` — 14-day feature monitor vs the training distribution.
- `04_decide_and_act.py` — morning green / amber / red report (default date 2026-04-20).
- `05_feedback_loop.py` — hold-on-red versus wait-for-MAPE, on the hook window.
- `06_charts.py` — the figures used in the video.
- `data_dictionary.md`, `CHALLENGE.md`.

## Data files

Every CSV in `data/` is well under 1 MB. If a chart PNG is missing from a GitHub checkout, run `./run_all.sh` to regenerate it.

## Important rule

`incident_log.csv` is the answer key. The demand model and the drift monitor do not use it at prediction time. `known_changes.csv` is a marketing calendar used only in the feedback discussion.
