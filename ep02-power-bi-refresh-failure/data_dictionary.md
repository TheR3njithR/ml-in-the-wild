# Data dictionary (synthetic)

All files are generated by `make_data.py`. Nothing here is from a real Power BI tenant.

## refresh_history.csv
One row per scheduled refresh of one dataset.

| Column | Meaning | When it is known |
|---|---|---|
| date, dataset, workspace | Who is refreshing, and on which morning | Ahead of time |
| scheduled_at, started_at, ended_at | Clock times | Schedule is known ahead; start/end only after the run |
| status, duration_min | success or failed, and how long the run lasted | After the run. **Do not use as a feature** when predicting this run |
| size_mb | Planned dataset size (MB) | Before the start (source / last metadata) |
| credential_age_days | Days since the source credential was last rotated | Before the start |
| gateway_online, mem_now, mem_mean_1h, mem_max_1h, mem_over_90_min, cpu_mean_1h, capacity_mean_1h | Gateway and capacity snapshot at **T-60** | Before the start |
| concurrent_running, queued_next_90m | Other refreshes already running at T-60, or scheduled in the next 90 minutes | Before the start |
| size_vs_28d | size_mb vs the previous 28-day median for that dataset | Before the start |
| duration_trend | Recent successful durations vs a longer baseline (previous runs only) | Before the start |
| failed_yesterday, is_monday, is_month_end | Simple flags | Before the start |
| notice_delay_min | Simulated minutes until a human reads the failure email (failures only) | After the failure; used to describe the email-only process |

## gateway_heartbeat.csv
One-minute metrics for the shared on-premises gateway, 04:00–10:00 each morning: `ts`, `gateway_mem_pct`, `gateway_cpu_pct`, `capacity_pct`, `gateway_online`.

## close_calendar.csv
Month-end close days the business already publishes (`date`, `event`).

## incident_log.csv
Ground-truth failure reason for each failed run (`date`, `dataset`, `workspace`, `incident`). **The model never sees this at prediction time.** It is the answer key used only to grade the model. Incident types: `GATEWAY_MEMORY`, `GATEWAY_OFFLINE`, `CREDENTIAL_EXPIRED`, `CAPACITY_THROTTLE`, `REFRESH_OVERLAP`, `SIZE_JUMP`, `SOURCE_TIMEOUT`, `NETWORK_BLIP`.
